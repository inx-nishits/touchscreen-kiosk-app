# KIOSK DEMO SCRIPT (FOR MOBILE)

## 1. INTRO
- Goal: Showcase "Video-First" design on 43" 4K Windows hardware.
- Focus: Premium aesthetics and cinematic experience.

## 2. IDLE SCREEN (ATTRACT LOOP)
- UI: Minimalist "Bulgarian Gold" accents.
- 4K Check: High-res typography (Outfit/Inter fonts).
- Kiosk Note: Cursor is hidden; app scales perfectly to 3840x2160.

## 3. INTERACTIVE MAP
- Hotspots: Animated "Beacons" draw attention.
- UI Style: "Glassmorphism" (blur/transparency) overlays.
- Touch: Hotspots sized for physical finger-tapping (6vw).

## 4. VIDEO PLAYER
- Transition: Instant playback via background pre-warming.
- UI: Minimal navigation (Home/Back/Progress).
- Logic: Returns to map automatically when video ends.

## 5. WINDOWS ENHANCEMENTS
- Triple-Tap: Top-right corner toggles Fullscreen (F11).
- Lockdown: Right-click/Menus disabled for security.
